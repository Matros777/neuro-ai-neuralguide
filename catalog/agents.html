категория · ИИ-агенты

ИИ- агенты

Софт для автономных ИИ-агентов: не просто чаты, а программы, которые сами ставят задачи, работают с файлами и кодом, вызывают инструменты и доводят дело до результата.

введение

Агенты — это не чаты

Обычный чат-бот отвечает на вопросы: вы спросили — он ответил. ИИ-агент — это программа, которой можно поставить цель, и она сама решает, какие шаги выполнить: пишет и правит код, создаёт и редактирует файлы, запускает команды, читает документацию и обращается к инструментам — пока не доведёт задачу до результата.

Чат vs агент
Чат — отвечает на запросы, не влияет на внешний мир.
Агент — действует: выполняет команды, меняет файлы, повторяет шаги при ошибке.
Чат — вы ведёте диалог вручную, шаг за шагом.
Агент — вы даёте цель, агент строит и исполняет план.
Локальный запуск
Многие агенты и модели предназначены для локального запуска — на вашем ПК, без облака.
Данные не покидают машину, приватность выше, нет ежемесячных плат.
Требуют ресурсов: чем мощнее модель и GPU/RAM, тем лучше результат.
Хорошо сочетаются с локальными LLM-серверами (Ollama и аналоги).

сервисы

Софт для ИИ-агентов по порядку

OpenCode

терминальный агент
официальный сайт ↗

OpenCode — opensource ИИ-агент, который живёт прямо в терминале (TUI). Работает как аналог Claude Code и Cursor, но в консоли и без привязки к одной модели: подключает OpenAI, Anthropic, Gemini, а также локальные модели через серверы вроде Ollama. Пишет код, правит файлы, запускает команды — и всё это локально и настраиваемо.

зачем нужен

Автономная работа с кодом из терминала, полный контроль и приватность, бесплатность, поддержка локальных моделей без облака.

цена

Open Source — бесплатен; оплата только за используемые модели/API

как установить

  1. Установите через npm: npm i -g @opencode-ai/opencode (нужен Node.js).
  2. Или скачайте готовый бинарник под вашу ОС с официального сайта.
  3. Запустите opencode в папке проекта и укажите модель.
  4. Для локальных моделей подключите сервер (например, Ollama) как провайдера.
🔍 тонкости
  • Локально: при подключении Ollama весь трафик остаётся на вашем ПК.
  • Гибкость: переключать провайдера и модель можно в настройках без переустановки.
  • Для РФ: полностью работоспособен с локальными моделями, без зарубежных карт и VPN.

Hermes Agent

агентный фреймворк
репозиторий ↗

Hermes Agent — SDK и агентный фреймворк от Nous Research для построения автономных ИИ-агентов. Даёт структуру для планирования, работы с инструментами и многошаговых задач, ориентирован на автономность и контроль. Подходит разработчикам, которые строят собственных агентов, а не пользуются готовым чатом.

зачем нужен

Построение своих агентов, оркестрация шагов и инструментов, автоматизация сложных многошаговых задач, контроль над логикой работы.

цена

Open Source — бесплатный фреймворк

как установить

  1. Клонируйте репозиторий с GitHub.
  2. Установите зависимости (Python/Node по документации проекта).
  3. Настройте доступ к модели (локально через Ollama или облачный API).
  4. Соберите своего агента на основе SDK.
🔍 тонкости
  • Автономность: агент сам разбивает цель на шаги и выполняет их.
  • Гибкость: подходит под специфичные сценарии бизнеса.
  • Для локального: совместим с локальными моделями для приватности.
⚙ конфиг · вставим рабочий конфиг позже
# agent config placeholder
model: "ollama/llama3.1"
tools: ["code", "file", "shell"]
# ...

OpenClaw

агентная система
репозиторий ↗

OpenClaw — агентная система для автоматизации задач: управляет рабочим окружением, файлами, инструментами и процессами. Агент понимает команды на естественном языке, планирует шаги и исполняет их. Предназначен для локальной работы, давая пользователю контроль над всем, что делает агент.

зачем нужен

Автоматизация рутинных задач, работа с окружением и файлами, локальное управление процессами, персонализация агента под рабочие сценарии.

цена

Open Source — бесплатен

как установить

  1. Клонируйте репозиторий OpenClaw.
  2. Установите зависимости и настройте окружение по README.
  3. Укажите модель (локальную или API).
  4. Запустите агента и поставьте первую задачу.
🔍 тонкости
  • Контроль: агент спрашивает подтверждение на опасные действия.
  • Локальность: всё выполняется на вашей машине.
  • Расширяемость: инструменты и сценарии настраиваются под задачи.
⚙ конфиг · вставим рабочий конфиг позже
# openclaw config placeholder
agent: "assistant"
model: "ollama/qwen2.5"
confirm: true
# ...

Claude Code

терминальный агент
документация ↗

Claude Code — официальный терминальный ИИ-агент от Anthropic, работающий на моделях Claude. Глубоко понимает код, силён в рефакторинге, поиске багов и длинных задачах. Популярен у разработчиков благодаря качеству рассуждений и большой длине контекста.

зачем нужен

Высокое качество работы с кодом, автономное выполнение задач, рефакторинг и отладка больших проектов, интеграция с репозиториями.

цена

Подписка — платный доступ к моделям Claude (нужна зарубежная карта)

как установить

  1. Установите через npm: npm i -g @anthropic-ai/claude-code.
  2. Войдите в аккаунт Anthropic (требуется оплата).
  3. Запустите claude в папке проекта.
🔍 тонкости
  • Оплата из РФ: требуется зарубежная карта или посредник.
  • Качество: лидер по работе с кодом среди закрытых агентов.
⚙ конфиг · вставим рабочий конфиг позже

model: "claude-sonnet"
permissions: {allow: ["Bash"]}

Windsurf

IDE-агент
официальный сайт ↗

Windsurf — IDE-редактор со встроенными ИИ-агентами (от создателей Codeium). Объединяет автодополнение и автономных агентов, которые понимают весь проект и выполняют задачи в коде. Удобен для тех, кто хочет ИИ-агента прямо в привычном редакторе, а не в терминале.

зачем нужен

ИИ-агент внутри IDE, понимание всего проекта, автономное выполнение задач, автодополнение и рефакторинг в одном месте.

цена

Free — бесплатный тариф с лимитами
Pro — платный, расширенный функционал

как установить

  1. Скачайте Windsurf с официального сайта.
  2. Установите и войдите в аккаунт.
  3. Откройте проект и используйте ИИ-агента.
🔍 тонкости
  • Оплата из РФ: платный тариф может требовать зарубежную карту.
  • В IDE: агент работает с контекстом всего проекта.
⚙ конфиг · вставим рабочий конфиг позже
# windsurf config placeholder
model: "default"
agent: "enabled"
# ...
