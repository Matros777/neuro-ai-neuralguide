Локальные LLM-серверы

Серверы для запуска нейросетей на своём компьютере: без облака, без ежемесячных плат и с полным контролем над данными. Идеальный фундамент для локальных ИИ-агентов.

введение

Зачем запускать LLM локально

Локальные LLM-серверы — это программы, которые поднимают нейросеть на вашей машине и отдают к ней доступ по стандартному API (обычно как OpenAI-совместимому). Это удобно, когда важны приватность, отсутствие подписки или работа в офлайне. Загрузили модель — и она работает на вашем железе.

Почему локально
Приватность — данные не покидают ваш ПК.
Нет подписки — платите только за железо и электричество.
Офлайн — работает без интернета.
Для РФ — обходит блокировки и платёжные ограничения облаков.
Что нужно
Ресурсы — чем больше RAM и GPU, тем крупнее модель.
Модель — скачивается из репозитория (например, через Ollama).
Сервер — одна из программ из этого раздела.
Совместимость — отлично сочетается с ИИ-агентами из соседней категории.

сервисы

Локальные LLM-серверы по порядку

Ollama

проще всего
официальный сайт ↗

Ollama — самый простой способ запустить LLM локально. Одна команда скачивает и запускает модель, а встроенный сервер отдаёт её по OpenAI-совместимому API. Поддерживает десятки моделей: Llama, Mistral, Qwen, DeepSeek и другие. Отличный выбор для старта и для подключения локальных моделей к ИИ-агентам.

зачем нужен

Локальный запуск LLM одной командой, работа без облака, приватность, лёгкое подключение к агентам и приложениям через API.

цена

Бесплатно — только ресурсы вашего ПК

как установить

  1. Скачайте установщик с ollama.com (Windows/macOS/Linux).
  2. Установите и запустите сервер (в фоне).
  3. Выполните: ollama run llama3.2 (или любую модель).
  4. Используйте API на http://localhost:11434.
🔍 тонкости
  • Список моделей: ollama list — показать установленные.
  • Размер: модели весят от единиц до десятков ГБ — нужна память.
  • OpenAI-совместим: многие приложения подключаются к Ollama как к OpenAI.
⚙ конфиг · вставим рабочий конфиг позже
# запуск модели
$ ollama run llama3.2

# API endpoint
http://localhost:11434/v1/chat/completions

LM Studio

графический UI
официальный сайт ↗

LM Studio — графическое приложение для запуска локальных моделей без терминала. Ищет и скачивает модели, даёт удобный чат-интерфейс и встроенный локальный сервер с OpenAI-совместимым API. Отличный выбор для тех, кто хочет запускать LLM, не вникая в командную строку.

зачем нужен

Локальные модели с графическим интерфейсом, поиск и скачивание моделей, чат и локальный API без командной строки.

цена

Бесплатно — с бесплатным тарифом для базового использования

как установить

  1. Скачайте LM Studio с официального сайта.
  2. Установите и откройте приложение.
  3. Найдите модель в поиске и скачайте её.
  4. Загрузите и чатите или включите локальный сервер.
🔍 тонкости
  • Удобство: всё в графическом окне, без консоли.
  • Настройки: контроль контекста и производительности.
  • Локальный сервер: включает API для подключения приложений.
⚙ конфиг · вставим рабочий конфиг позже
# lm studio server (включить в настройках)
port: 1234
api: "openai-compatible"
model: "qwen2.5-7b-instruct"

llama.cpp

лёгкий движок
репозиторий ↗

llama.cpp — легковесный движок для запуска LLM, оптимизированный под разные устройства, включая слабое железо и даже без GPU. Это «движок», на котором основаны многие локальные решения. Включает llama-server — сервер с OpenAI-совместимым API.

зачем нужен

Локальный запуск моделей на слабом железе, экономия ресурсов, гибкий контроль, работа на CPU без GPU.

цена

Бесплатно — open source

как установить

  1. Соберите из исходников или скачайте готовый бинарник.
  2. Запустите llama-server с указанием модели.
  3. Получите API на локальном порту.
🔍 тонкости
  • CPU-дружелюбен: работает даже без видеокарты.
  • Квантование: уменьшает размер моделей ценой небольшой потери качества.
  • Основа: на нём построены многие локальные серверы.
⚙ конфиг · вставим рабочий конфиг позже
# запуск llama-server
$ llama-server -m "model.gguf" --port 8080
# API: http://localhost:8080/v1/chat/completions

vLLM

высокая нагрузка
репозиторий ↗

vLLM — высокопроизводительный сервер для LLM, оптимизированный для больших нагрузок и продакшена. Использует эффективное управление памятью и пакетную обработку, поэтому выжимает максимум из GPU. Отдаёт модели по OpenAI-совместимому API. Выбор для серьёзных задач и команд.

зачем нужен

Продакшн-деплой моделей, высокая пропускная способность, работа с большим числом одновременных запросов, максимум от GPU.

цена

Бесплатно — open source; нужен мощный GPU

как установить

  1. Установите через pip: pip install vllm.
  2. Запустите сервер, указав модель.
  3. Получите API для высоконагруженных приложений.
🔍 тонкости
  • Требования: нужен мощный GPU и память.
  • Производительность: одна из лучших на рынке локальных серверов.
  • Для продакшена: промышленный стандарт для деплоя моделей.
⚙ конфиг · вставим рабочий конфиг позже
# запуск vllm
$ vllm serve "meta-llama/Llama-3.1-8B" --port 8000
# API: http://localhost:8000/v1/chat/completions

LocalAI

замена OpenAI
официальный сайт ↗

LocalAI — локальная альтернатива OpenAI API: предоставляет тот же интерфейс, но работает на вашем железе без облака. Поддерживает не только LLM, но и другие модели (аудио, изображения). Удобен, чтобы переключать приложения с облака на локаль, не меняя код.

зачем нужен

Локальная замена OpenAI API без смены кода, приватность, работа с LLM и другими моделями, бесплатный локальный деплой.

цена

Бесплатно — open source

как установить

  1. Скачайте LocalAI (бинарники или контейнер).
  2. Запустите сервер.
  3. Подключите к нему приложения как к OpenAI API.
🔍 тонкости
  • Совместимость: API-совместим с OpenAI, код менять не нужно.
  • Мультимодальность: кроме текста, есть модели для звука и картинок.
  • Для РФ: полностью локально, без платёжных барьеров.
⚙ конфиг · вставим рабочий конфиг позже
# localai env
OPENAI_BASE_URL: "http://localhost:8080/v1"
MODELS: "llama3"
